# 动作参考与原生网格重画

适用于小尺寸像素角色张嘴、打哈欠等需要补画隐藏结构的动作，尤其是整组生图已改变角色身份时。不是自动生成人脸或嘴部的 CLI 模式；不要把本案例参数套到其他角色。

## 制作顺序

1. 查看原图，记录原生尺寸、像素网格、主色块尺度与透明轮廓。把眼、上吻部、鼻、下颌、颈部和衣领分清；声明允许编辑的区域，包含下颌完整运动范围及其遮挡的衣领。保留原图和已认可序列。
2. 用可用的参考图编辑工具生成闭嘴、半张嘴、最大张嘴的关键姿势；用户指定 imagegen 时使用它。先检查角色身份、侧面方向、上下颌连接和口腔位置。生成图只作结构参考时，不把其中嘴部裁切后直接缩放、拼贴到原图。
3. 在原生网格上逐帧重画眼睑、口腔和下颌，复用未动的原像素。Aseprite 可保留固定身体层和局部动作层，并用 Lua 批量构帧；其他能控制像素网格的工具也可用。保留可编辑源文件，Aseprite 并非其他流程的必需依赖。
4. 下颌从靠近脸颊的连接处打开，保持有厚度的外轮廓；暗色口腔应位于上下颌之间，不能变成颈部洞或悬空黑块。长吻角色的小幅哈欠可固定鼻与上吻部；需要抬头时另行规划完整头部运动，不能拉伸嘴部冒充。移动下颌前，补好其后方实际会露出的颈部或衣领。
5. 安排静止、眯眼、逐渐张嘴、峰值短停、闭嘴和恢复。以实际播放时间控制速度，允许少量重复姿势表达停顿。恢复类动作可首尾相同，但仍检查最后闭合、恢复眼神与循环停顿；不能只以首尾相等判定自然。

## 保持粗像素质感

- 放大仅供观察和展示。原图 32×42 放到 64×84 后直接画单像素线条，会引入半个原生像素的细节；最近邻放大无法消除已画入的细碎结构。
- 优先在原生尺寸绘制，最后统一整数倍最近邻放大。必须在放大画布工作时，绘制须遵守原网格的尺度和相位，不能只约束画布尺寸。
- 原生网格只是最低约束。原图若主要由 2×2 色块构成，新轮廓仍应采用连贯色块，减少孤立单像素牙齿、舌尖、眼睑和阶梯。不要机械量化整张原图或强迫全部细节变成 2×2。
- 简化应保留已认可的下颌厚度、开合节奏和固定部位。盲目缩小整段动画可能丢掉下颌连接，必须重新审阅。

## 检查与交付

- 每次修订查看最终全部帧、脸部放大和 N-1→N→1→2；检查鼻与上吻部是否漂移、下巴是否脱离、颈部是否露洞、眼睛是否错位，以及新旧区域的像素密度是否一致。
- 逐帧比较预先定义的固定区 RGBA；另外检查透明洞、开放缺口和遮挡。固定区零差异不证明嘴部结构合格。
- 有播放器时播放最终 GIF。仅采样播放截图时如实记录，不能声称已连续观察完整动画。静态审阅、程序验证、播放观察和用户评价分开记录。
- 交付透明 PNG、GIF 和可编辑工程，记录原生尺寸、工作尺寸、展示倍率、时长、PNG 数、独特画面数与 GIF 实存帧数。复用共用视觉检查要求，不以数字检查替代验收。

## 本次案例的证据与边界

32×42 的西装狼经过三姿势生图参考，再在 Aseprite 中重画连贯下颌，得到 12 帧 PNG、9 个独特画面。用户评价为“还行，没有明显大错”，同时指出“像素感觉多了很多”。原身体被放大为 64×84，但新嘴部在放大网格上逐像素绘制，造成新旧像素尺度不一致。

因此本次只确认动作结构基本可接受；原生网格重画和粗色块简化是下一步修正方案，尚未完成并得到用户验证。不要把本参考描述为已解决像素密度问题的成品，也不要以该角色证明任意角色均可复现。不发布用户原图、生成参考或机器路径。
