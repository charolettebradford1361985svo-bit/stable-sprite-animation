# 身体补全、逐帧完整性检查与头发摆动

用于部件移开后露底、身体边缘缺像素、肩腰连接不完整，或用户希望增加发束、衣角等局部次级运动。先锁定已认可的 PNG 基线、帧数和时长，再限定修改范围。以下是人工选区与本地绘制方法，不是现有 CLI 的自动补全模式。

## 身体底层先完整，再让部件移动

切出手臂或头发后，原位置不能只清成透明。按参考图重建被遮住的衣身、头皮或颈部，分开保存完整底层、活动部件和前景遮挡层。原图未展示的区域属于推定补画，应限制在必要范围，不声称是原像素。

- 先画出可信的躯干轮廓，覆盖肩、腋下、腰边和裤口；用原调色板补齐轮廓内缺口，并清理遗留的旧手臂边线。不要从修好后仍相同的像素反推保护区。
- 允许前景手臂盖住衣身，但手臂移开后底层仍须连续。双腿间、手臂与身体之间的正常负形空间应保持透明，不能用全图膨胀或填洞把肢体粘成一块。
- 若上身随步态移动，让头衣身与肩锚点共享同一小幅位移，脚底保留支撑轨迹。腰部下方预留被遮住的腿根重叠，避免上身抬起后露出一条透明缝。分别验证身体局部像素与脚底画布位置。
- 少量缺像素可以在已声明的补画区域内按相邻材质手工补齐。旋转后的小针孔若需要自动处理，限制区域与面积，记录数量并重看结果；不要自动填掉所有透明区域。

## 检查不能只盯一种“洞”

| 检查 | 能发现什么 | 不能证明什么 |
|---|---|---|
| 不透明主体连通分量 | 意外脱落的肢体或像素碎片 | 连成一块仍可能缺边或变形；独立道具/特效可有合法分量 |
| 透明区连通到画布外缘的检测 | 没与外背景相通的封闭针孔 | 连通到外部的肩、腰缺口会被漏掉 |
| 预先定义的实体覆盖掩码 | 应有衣身的位置却是透明，包括开放缺口 | 错误或过小的掩码会给出错误安全感，须对照原图审阅 |
| 高对比透明底放大图 | 区分透明背景、浅色布料及真实关节间隙 | 静态图片不能代替运动自然度判断 |
| 解码 GIF 与 PNG 预览比较 | 调色板、透明索引、处置方式等导出差异 | 相同的错误画面仍会比较通过 |

对于本案例的二值 alpha 图，每帧将实体覆盖掩码随身体位移，统计 `coverage & (alpha == 0)`；同时检测封闭背景分量和前景连通情况。半透明边缘、烟雾或独立特效需另定规则，不能套用“全图必须不透明/只有一个分量”。检测结果须指出检查区域、坐标系和未覆盖的部位，不能直接称“整个身体完全正确”。

逐帧检查合成后的实际图片，而不只检查部件原图。浅灰衣料与灰底很接近时，换高对比审阅底色辨认 alpha；换背景只改善可读性，不是补洞。本案例衣料 RGB 213 与旧底色 218 很接近，因此保留透明 PNG，改用更有对比的预览底色。

GIF 检查先按最终裁框、背景、缩放和调色板制作预期 RGB 帧，再解码每一帧比较，同时检查时长与循环设置。本案例颜色能无损装入调色板，所以逐像素一致；需要有损量化的素材应明确比较量化后的预期帧或误差，不能对未量化 PNG 承诺零差异。GIF 合帧时按累计播放时刻比较，不误报为 PNG 缺帧。

## 头发要有完整发束与固定发根

先分清帽子、脸、固定头部、近侧短发束和后侧长发束。根据用户指定的运动范围决定是否需要补画局部素材；只让发梢外缘几个像素伸缩，在小角色上往往像噪点，不能表现整束头发的重量。

1. 从同一静图提取可用发束；旧裁片若包含黑色切口、轮廓碎点，局部重画为连续、有体积的发束，沿用角色配色和发长范围。不需要重画整个人物，也不默认调用外部生图。
2. 发根固定在头部局部坐标，长发束与短发束分别绕根摆动。用与步态相关、略有滞后的周期安排回摆；长发幅度较大，短发较小。根部随已认可的上身位移移动，不与头部分离。
3. 帽子与脸在正确的前景层遮住根部，发束移开处保留完整头皮/颈部底层。前景脸部保护区不得被补画或摆动意外覆盖。
4. 像素图使用最近邻采样；旋转也可能制造锯齿、小孔或轮廓碎点。检查整束外形，而非只看角度公式；必要时补轮廓、简化碎线和修针孔，再重新渲染检查。
5. 保留已认可的腿、鞋、摆臂和节奏，逐帧比较局部修改范围以外的 RGBA。实际摆动可能显露原本不可见的区域，预先把补底范围纳入授权的局部修改区。

## 已认可案例记录

红发绿帽角色最终采用两束发层、局部补画发根底层及完整衣身轮廓检查，用户认可结果；原素材和角色专用脚本不随公开包分发。以下参数仅用于理解本案例，其他图不能照搬：

- 12 帧，每帧 120ms，一轮 1.44 秒；制作原生网格为 32×48，输出工作画布为 96×112，角色按 2 倍最近邻放大后加留白。
- 上身输出像素位移：`dx=[0,0,1,1,0,0,0,0,-1,-1,0,0]`，`dy=[0,1,0,-1,-1,0,0,1,0,-1,-1,0]`。这是工作画布上的整数位移，即半个原生像素；保留色块，不插值模糊，不宣称原生网格位置完全不变。
- 后发束角度：`[8,0,8,20,28,20]` 重复两次；前发束：`[-2,0,-2,-6,-10,-6]` 重复两次。枢轴在头部局部坐标，随后应用身体位移；这是可控摆动，不是毛发物理模拟。
- 旧版虽无封闭 alpha 洞，扩大到可信完整衣身轮廓后仍发现每帧 4–16 个输出像素的开放缺口。它说明“无封闭洞”与“身体完整”不能等同。
- 最终 12 帧的已定义衣身区缺口为零、封闭 alpha 洞为零；该角色前景保持一个连通分量，解码 GIF 与预期 PNG 预览一致。数值证据与用户认可分别记录，不推广成任意角色的质量保证。

## 每次修改后的交付检查

重新查看全部帧联系表、改动区域放大图、高对比透明底图和 `N-1→N→1→2`。发现问题则修复并重看新输出，不能在第一次候选审阅后继续改图却沿用“已检查”。有播放器时播放；没有时如实记录静态审阅范围。

保存 PNG、GIF、运动记录、修补/覆盖掩码、验证报告及 `visual-review.json`。报告包括问题帧、修补数量、轮廓检查区、保护区差异、导出一致性、实际看过的最终文件和播放状态。用户认可可以记录，但不能替换 agent 自己的检查，也不能将静态审阅写成播放验收。
