# 对象分类与视觉案例

分类只回答“先看哪组经验”，不自动决定坐标、幅度、时长或合成层级。先观察原图及所需动作，再记录对象类型、可见结构、视角、原生像素尺度、固定部位与运动范围；无需填写冗长表格。对象复合时按部件组合参考，结构不符时退出案例，不强行套模板。

## 角色

| 已有经验类型 | 动作与观察重点 | 制作参考 |
|---|---|---|
| 短粗腿双足 | 走路保持整腿和鞋型，以小步和承重表达；不强求明显交叉 | [步态选择](gait-readability.md)、[整腿走路](cutout-walk.md) |
| 长腿／膝部可见双足 | 走路明确近远腿身份、经过位、前后换腿、鞋视角和手臂遮挡 | [斜侧走路](three-quarter-walk.md) |
| 短腿角色跑步、小跳 | 仍用原腿型，但按动作区分腾空、蓄力与落地；走路参数不能直接替代 | [跑步](cutout-run.md)、[跳跃](cutout-jump.md) |
| 局部面部动作 | 按吻部和下颌结构补画，与长短腿分类无关 | [原生网格重画](native-grid-redraw.md)；狼案例仍有像素过细问题 |

前两类有用户认可的制作经验，不代表同类新角色已经验证。四足、飞行和特殊结构暂不建立成功模板；按实际关节、支撑和可见素材设计，并说明尚无匹配案例。

## 物品／环境物

| 类型 | 状态 | 制作范围 |
|---|---|---|
| 固定支架上的悬挂旗布 | 旗子轻微飘动获用户认可 | 分离杆、横梁、固定点与布面；固定点位移接近零，布面随远离固定点逐步增加小幅周期变化。完整保留布面纹理，避免散点抖动或整杆摇摆。逐帧检查连接、露底与循环。需按图片制作局部流程，没有现成旗布 CLI |
| 树木及散落叶片 | 仍待验证，先前结果被否决 | 树根／树干、树冠和脱落叶片分别设计；树体摇摆与叶片出生、下落、消失是不同过程。不能拿旗布变形直接当树木成功方案，也不能将被否决结果当目标图 |
| 其他物品 | 暂无认可案例 | 按刚性连接、铰链、柔性区域或粒子生命周期分析，不凭物品名称自动选动画 |

## 如何使用图片

读取本页后，打开 [图片索引](visual-examples.md) 中与任务匹配的一组 PNG 联系表或关键帧，而非仅阅读文件名。对照原图判断结构和方法是否适用。GIF 用于节奏检查；工具只能读取首帧时，改看联系表并如实说明没有播放。看图不等于获得该案例的通用参数。

区分三种证据：用户认可的历史结果、原理示意、未通过候选。说明原图来源、展示倍率、认可范围和限制；不要把示意图包装成已通过的动画。公开包不包含授权不明的历史素材；本机补充案例可独立保存，不能让公开版引用不存在的必需文件。
