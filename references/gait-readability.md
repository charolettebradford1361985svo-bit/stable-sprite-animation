# 按角色结构选择走路表现

走路的可读性不等于每帧都把两条腿明显分开。先看原生尺寸下可见的腿段、腿宽、膝部、衣摆遮挡、视角以及最终显示尺寸，再选表现方式；不用统一腿长阈值或固定步幅套所有角色。

| 结构与可见条件 | 优先表达 | 避免 |
|---|---|---|
| 可见腿段较长，膝与鞋可辨 | 两次接触位能读出前后腿交换；经过位有抬脚、适度屈膝和连续遮挡 | 两腿只开合、同一脚重复踢出、经过位突然换身份 |
| 短粗腿、脚块很小，或衣摆遮住大部分腿 | 保留腿型，用短距离前后移动、轻抬落脚与受控换重心表达节拍；可辅以同步的小幅摆臂 | 为展示交叉拉长腿、压成细条、拆成夸张 Z 形膝，或扩大步幅破坏角色比例 |
| 正面、严重重叠或低分辨率难辨前后 | 根据投影表达左右承重、脚底接触和遮挡变化，不强求侧视交叉剪影 | 机械套侧面轨迹，靠翻转鞋子伪造换腿 |

这里区分的是**动作的交替与交替的视觉显著程度**。短腿不一定要看出明显的两腿交叉；也不是两脚可以一直固定、只让身体上下跳。普通双足行走仍应有可信的支撑交换和方向感。若用户明确要求滑行、拖步或其他风格化步态，按该动作另定标准。

## 选择与验收

1. 先以原腿型和小幅动作试出接触、经过、对侧接触几个关键姿势。长腿查看换腿是否清楚；短腿先看原比例、落脚节奏与整体走路感，不急着增加膝部细节。
2. 同一周期协调腿、手臂和允许的身体位移。身体起伏是辅助线索，不能掩盖脚底滑动、双脚同步蹦跳或无意义像素抖动。用户要求身体固定时，依靠脚步和允许运动的部件表达，不擅自增加起伏。
3. 在最终显示尺寸播放，再放大检查连接和缺口。长腿检查近远腿身份、经过位和两次接触位；短腿允许短暂重叠及量化后的重复姿势，只要有可信的落脚和连贯节奏。不为了每帧“看起来不同”制造抖动。
4. 保留已认可部分。用户接受短腿的小步风格后，不为追求长腿式交替重新造腿；长腿交替不清时先查轨迹、遮挡和节奏，而不是只增加身体起伏。

小步整腿制作见 [原图部件走路](cutout-walk.md)；需要膝部与近远遮挡的斜侧角色见 [斜侧角色走路](three-quarter-walk.md)。这是制作方法选择，不改变现有 CLI 的半周期、支撑或导出检查，也未新增自动判断角色比例的功能。

## 依据边界

本次用户对长腿红发角色与短腿鳄鱼的走路提出对比反馈：前者需要清楚的腿部交替，后者不一定需要同等显著的表现。此次收到的两份附件都是单帧 PNG，可支持比例与轮廓观察，不能用于确认完整播放、帧序或运动参数。上述总结结合用户反馈与已有制作经验，未新增动画实验或逐帧播放验收；不公开附件素材。
