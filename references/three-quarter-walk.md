# 斜侧角色走路：脚轨迹、膝部投影与手臂遮挡

先按 [步态表现选择](gait-readability.md) 判断需要多显著的换腿效果：动作相位与画面中腿部交叉的显著程度不是同一要求。

适用于露出膝部、近远腿能辨认的斜侧像素人形角色。整腿刚性剪贴若像开合跳，可改用固定鞋素材、受控腿部连接和独立手臂层。由 agent 为输入角色写局部渲染脚本；现有 `cutout_walk.py` 没有此模式，不能把本文参数直接传给它。

## 已认可案例与边界

案例是一张红发绿帽角色静图，在原生 32×48 网格制作 12 帧。输入链接本身是动画，但制作仅使用第一张静态图；最终腿、鞋和手臂不复用原动画其他帧，也不使用被否决的生成腿图。

用户认可本篇的初版走路，但指出浮动感。后续已认可的改进包括身体补全、小幅承重位移及整束头发摆动，见 [身体补全与次级运动](integrity-and-secondary-motion.md)。下面仍保留初版腿与手臂参数作基线，不声称它“已完全自然”。检查过联系表、部位放大图和循环边界；agent 没有实际播放验收，用户对 GIF 的反馈单独记录。案例素材不随包公开。

## 制作顺序

1. **恢复原生网格。** 对最近邻放大图确认整数倍率，在原生像素网格安排动作，导出时最近邻放大。先保留参考静图、原始调色板、固定头衣身和已认可输出。
2. **按解剖身份命名。** 近侧腿、远侧腿分别绑定自己的鞋和髋部；不要在脚交叉后按画面左右重新分配身份。先确定支撑、后蹬、抬脚、前摆、落地，再画中间姿态。
3. **用同一个周期驱动手脚。** 两腿相差半周期，手臂与同侧腿反向。用接触位和经过位对照手臂极值与中位，不能让生成腿图和手臂各自按不同的帧序推进。非 12 帧输入重新采样周期，不截断、重复这份样例凑帧数。
4. **检查投影和遮挡时间。** 两脚不能连续半个周期合成一只靴子。调整符合角色透视的髋间距、前后脚地面层和轨迹；短暂经过遮挡正常，但第二次接触位仍应看出换腿。前后地面高差是透视参数，不是给漂浮脚找借口。
5. **让膝盖适度弯曲。** 斜侧视角的二维投影长度可以缩短。硬求固定二维骨长，可能把抬起的膝盖横推出裤外。用窄幅膝偏移连接髋踝，保持原腿粗细和配色，检查裤口下方是否成横向肤色条带；不要逐行拉伸皮肤。完整裤腿的小步动作仍优先整腿剪贴。
6. **鞋视角作为素材问题处理。** 中性站姿中朝外的鞋尖，未必适合向前走。只有用户要求修鞋视角或动作确实需补画时，制作符合角色视角、尺寸和配色的鞋素材。鞋面、短鞋尖与鞋底应表达同一斜侧方向；仅镜像一只侧面鞋常会造成两鞋视角不一致。整轮使用固定近/远鞋素材，不逐帧翻转或变宽。
7. **先修遮挡，再增摆幅。** 近侧手臂前摆若总在身体后层，角度再变化也只会露出几颗像素。远臂在躯干后，近臂可跨到身体前；肩部锚点固定，保留手和袖管轮廓。按原图的初始手臂倾斜加角度偏置，再设置可辨的前后摆幅，别只机械扩大对称角度。
8. **局部修改冻结已认可运动。** 用户只要求鞋与手臂时，逐帧比较髋、膝、踝、鞋底轨迹、帧数和时长。身体底层不变，允许近臂按预先声明的层规则遮挡它；核查未遮挡保护区 RGBA 与原图相同，另存遮挡掩码。不要把遮挡后的合成图称为“每个身体像素都没变”。

## 本案例的可复现参数

以下为原生图坐标，未经填边或放大。仅适用于本案例结构，其他角色需重新选锚点。它是局部渲染配方，不是通用 CLI 配置。

- 12 帧，每帧 120ms，一轮 1.44 秒；头和衣身无整体位移。
- 近髋 `(15.5,39)`，远髋 `(17.5,39)`。
- 近脚鞋底 x：`[12,12,13,15,17,18,19,18,17,16,15,13]`。
- 近脚鞋底 y：`[47,47,46,45,46,47,47,47,47,47,47,47]`。
- 远脚取近脚序列向前偏移 6 帧，x 加 2、y 减 1；近/远地面分别为 47/46。支撑脚沿各自地面向后移动，每帧至少一脚支撑。
- 踝点为鞋底锚点减 `(0,3)`；抬脚高度 `lift = 本侧地面 - 鞋底y`。
- 膝点 `0.55*髋 + 0.45*踝 + (0.25 + 0.3*lift, 0)`。这是受控二维绘制，不宣称固定真实骨长或物理仿真。
- 腿外层宽约 2.6px，肤色内芯约 1px；取整后目视核查。不是任何角色的标准宽度。
- `θ=2π*i/12`；近臂角度 `-12 - 32*cos(θ)`，远臂 `8 + 28*cos(θ)`。在本案例图像坐标下绕肩旋转，最近邻采样；换角色需重定偏置、方向和幅度。
- 图层顺序：远腿、近腿、远臂、固定身体、近臂。头、衣身、原裤型来自静图；旧手臂位置先清除并检查切口。
- 最终近/远鞋使用固定紧凑斜侧素材，沿用原图深色轮廓和红棕调色板。更换的是鞋视角，不是整条腿的运动。

## 失败方式与验收

| 失败方式 | 应采取的修正 |
|---|---|
| 生图每帧腿的身份或形状不同 | 重建固定身份的部件轨迹；不能靠调序、降低帧率或首尾相似掩盖 |
| 只重排姿态与放慢 GIF | 可缓解速度，但不能修复错误动作；不要据像素变化下降宣称自然 |
| 固定二维骨长造成横折膝 | 控制投影膝偏移、腿宽和裤口连接，检查过渡轮廓 |
| 两腿长时间合成粗柱 | 检查髋投影间距、脚轨迹与近远层次，查看两次接触位 |
| 手臂角度变化但只见像素抖动 | 检查躯干遮挡和肩锚点，再增加实际可见手部位移 |
| 鞋尖反向或两鞋视角不一 | 在已授权修鞋范围内制作固定的对应视角素材 |

导出透明 PNG、GIF、运动记录及固定区域/遮挡验证。检查每条腿完整完成一轮动作，查看 `N-1→N→1→2`、实际脚底与截图中的膝鞋连接。数值通过与用户认可分开记录。

**承重感的边界：** 上述初版头衣身完全固定，即使脚底满足支撑条件，也不能证明有真实承重。后续在用户要求下加入小幅上身位移并获得认可，具体方法见补全参考；这不代表物理准确。继续调整时对照播放检查支撑时长、脚底滑动、透视地面和重心转移，不把自动上下抖动当作通用补救，也不覆盖已认可版本。
