# 参考图整组生图路径

用于需要新造型、隐藏部件或特效的动作。完整部件足以制作的小步走路，先考虑入口中的原图部件路径。

1. 查看原图，按动作划分动静区域。运动区包含完整运动轨迹、遮挡变化和特效；选有纹理的静止区域作注册锚点。全身都在移动且没有静态锚点时，这个注册器不适用，需要明确的根节点/姿势控制。
2. 在新的运行目录准备画布：

   ```text
   python <skill-dir>/scripts/sprite_workflow.py prepare --image <transparent-character.png> --action "打喷嚏一次，然后恢复" --frames 12 --out <run-dir>
   ```

   生成 `seed-frame.png`、`reference-canvas.png`、`prompt.txt`、`run.json`；保留源分辨率与 alpha，默认每边约 20% 留白，必要时用 `--padding LEFT TOP RIGHT BOTTOM` 调整。
3. 查看带边距的种子帧，依 [配置](run-config.md) 填写运动区、注册锚点、循环和探针；坐标相对带边距的帧，锚点不能落在运动区。按 [提示词参考](prompting.md) 写指定数量的完整动作节拍。
4. 使用批准角色与准备画布，一次生成整个透明图集。统一比例与方向，精确行列与帧数，无文字、格线、贴纸描边。以实际返回的文件尺寸为准；不要逐帧独立生成或逐角色独立缩放。
5. 将生成静止姿势与原图并排检查。头身比例、接缝或动作不合格时，修素材；不能用固定身体掩盖错误。恢复类动作使用 `rest`：从本次生成组中选择特效消失、已自然静止的 `rest_frame`，不能猜倒数第二帧，也不能硬塞外部原图。连续步态用 `cycle`，单次动作用 `none`。
6. 合成导出：

   ```text
   python <skill-dir>/scripts/sprite_workflow.py finalize --run <run-dir> --sheet <generated-transparent-sheet.png>
   ```

   整组共享缩放，各帧只作平移注册；只有运动区使用生成像素，区外 RGBA 直接复制种子帧。保证不覆盖运动区内的形变。检查低分注册、裁切、额外格子、透明度等报告问题。
7. 验收整组以及循环。原 A 修正版的关键是用本组自然静止帧替换循环端点，消除生成姿势突然切回外部原图的跳位；仍必须检查新的 `1→2`，以及进入/离开连续静止段的实际过渡。探针不能只放在被硬复制的身体上；缺少有效探针只能标记未验证。

导出和视觉记录要求见技能入口。机器检查通过不代表动作语义或观感通过。
