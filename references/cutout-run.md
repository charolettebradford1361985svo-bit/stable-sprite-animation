# 保持短腿轮廓的跑步

用于朝向不变、脚部能分离、衣摆遮住腿根的小幅像素跑步。基于一次被用户认可的 32×42 角色实验；没有证明任意角色都能自然跑步。大跨步、明显屈膝或缺少原腿部件时，需要额外姿态素材。

本页指导 agent 编写本次角色的局部渲染脚本。`cutout_walk.py` 的支撑比例和验收要求至少一脚着地，固定层序也可能遮住前摆手臂；不要把跑步配置直接交给该脚本。

## 先保形，再调步态

1. 在原尺寸查看头、衣身、裤腿、鞋与配饰。裁框只取能确认的活动部件，衣摆不因靠近腿而一并切走。先用中立姿势复原源图：比较 alpha 和可见 RGBA，排除重复部件、漏掉裤裆及错误接缝。
2. 极小、短粗的脚块优先使用整数平移。最近邻旋转也可能把 4×4 的脚变成细尖；如果旋转破坏轮廓，减小角度或取消旋转，不靠加粗补丁修脚。
3. 左右腿错开半周期，并真正经过前伸、落脚后移、离地回收。仅让各自在原来的左右列上下抬落，会像踏步。按角色视角设置能前后交错的髋部轨迹；共同中心是此次样例的选择，不是所有视角的规定。
4. 跑步允许两脚同时离地。缩短单脚支撑，安排短暂腾空；身体只作受控整数位移，保持原轮廓。若用户要求身体绝对固定，起伏设为零，仍由脚步与手臂表达动作。
5. 空手与同侧腿反向摆动。小幅上臂摆动配合短前臂抬起，比把整条手臂剪切成一条长斜线更容易表现跑步。后摆可以被躯干遮住，前摆的前臂可局部放到衣身前方，避开领口和脸。提包侧见 [提包手臂](carrying-arm.md)。

不要把所有部件一律放在身体后面。逐帧检查脚交错时的前后层次：此次抬高脚在前，有利于保留其脚底，低脚的脚底也仍可见；其他角色按实际遮挡决定。两只脚处于同一高度且重叠时，不可能要求同一像素同时等于两种原色，应修轨迹/层序或明确合理遮挡，不能伪造验证通过。

## 已认可的 12 帧参考

[紧凑角色跑步参数](examples/compact-run-12.json) 保存这次的原图坐标、步态、手臂和提包参数。它是**制作参考，不是现有 CLI 的配置格式**；不含原图或私人路径。其他角色重新选部件、重排轨迹。其他帧数重新采样完整周期，不能截取或重复这 12 项凑数。

- 源图 32×42；透明输出画布 64×64，源图统一放在 `(16,8)`，不逐帧裁切或居中。
- 两只可见脚块各 4×4，衣摆以上保持完整。两条腿相差 6 帧，使用同一前后轨迹；脚底按地面与抬脚高度定位，身体起伏另外计算。
- 每帧 60ms，共 720ms；12 张独特 PNG、12 个 GIF 实存帧。第 4–6、10–12 帧腾空，身体上移 1 个源图像素，其余身体位移为零。
- 最终提包手小幅摆动，与空手大致反向；包保持原形并与手一起平移。头、腿和空手与此前已认可版本逐帧一致。

连续动作从 `[0,1)` 采样，不添加静止终点。检查 `N-1→N→1→2`，让第 N 帧继续进入下一次落脚，而不是跳回站姿。

## 验收

- 在最终合成帧中检查可见脚底的宽度、alpha 与原色，并看腿根、衣摆和两腿交错。此次数值检查保住的是 4 像素脚底，不能据此声称每条腿的所有行均已验证。
- 身体允许整体平移时，在身体局部坐标检查预先声明的固定区域。活动手臂/包覆盖衣身属于遮挡，保存这些遮罩与位移；不要把颜色覆盖当作原身体层被缩放。
- 对照原图和整组联系表，检查踏步感、腿变细、直臂僵硬、断口、道具与尾巴。指标通过后仍需目视判断动作语义。
- 局部修订与已认可 PNG 序列逐帧比较，只允许声明的编辑区变化；固定头、腿和另一只手的既有运动与时长。
- 保存 PNG、GIF、参数、运动记录和实际视觉检查范围。此次 agent 检查了静态联系表、脚部/手臂放大图及循环边界，未实际播放 GIF；用户查看后认可。区分程序检查、agent 静态检查和用户评价。
