# 保留原腿型的原地小跳

用于朝向不变、原图双腿和鞋子完整、腿根可藏在衣身下的小幅跳跃。这个样例被用户接受为“没有明显错误、中规中矩”；它是可复现的基础动作，不是任意角色自然跳跃的保证。

## 方法

每条原裤腿和鞋子保留为一个完整部件，**只作整数平移**，不分膝、不拉长、不压细、不旋转或镜像鞋子。站地时腿和鞋不移动，身体小幅下沉遮住部分腿根，形成浅蹲；随后身体回升、整个人物腾空。空中可少量收拢双腿，但不要超过原部件与衣身的重叠范围。

腾空按实际播放时间计算 `y = -round(4 × height × u × (1-u))`，`u` 为起飞后的时间占总腾空时间的比例。上升和落地附近移动较快，顶点附近较慢。帧时长与采样时刻必须一致，不能只画一条正确曲线却用另一种节奏播放。

落地拆成 **接触地面 → 身体压低缓冲 → 回升 → 站稳**。落地期间脚底留在同一像素行，不让角色穿地或一触地就切回站姿。首末都是同一套部件合成的站姿，可以相同；相邻停顿属于单次跳跃的节奏，不套连续走路的首尾规则。

衣身最后覆盖腿根切口。头、身体、提包和尾巴按身体层整体移动，保留原像素；空手可以小幅刚性摆动。必须查看胯部和袖口的连接，不能把“整腿像素没变”当作合成后没有断口。

## 配置与运行

agent 查看角色原图后选择裁框、遮罩、锚点和节奏，用户不需要填写坐标。

```text
python <skill-dir>/scripts/cutout_jump.py --image <transparent-character.png> --config <jump.json> --out <new-output-dir>
```

脚本复用包内 `cutout_walk.py` 的渲染和导出工具，因此应保留完整技能目录。已认可的 [鳄鱼 12 帧配置](examples/croc-jump-12.json) 只适用于本次 **200×200 的透明原图**，不含原图或本机路径。其他图片重新选部件，不能按角色名字套坐标。

所有矩形使用输入画布坐标 `[left, top, right, bottom]`，右下不包含。PNG 保持输入画布尺寸；先给头顶留足腾空空间，不能逐帧自动裁切或居中。

| 字段 | 含义 |
|---|---|
| `frame_count` | 8–64，应与 `poses` 和手臂角度项数一致；脚本不自动补帧 |
| `ground_y` | 原图可见鞋底所在行，按 alpha≥128 判断；地面阶段保留原腿位置 |
| `flight.height_px` / `duration_ms` | 抛物线高度和腾空总时间；整数采样未必刚好取得顶点 |
| `body.clear_rects` / `fixed_boxes` | 移除活动部件的原位置；声明身体局部坐标中必须保持 RGBA 的区域 |
| `legs` | 两条完整腿，顺序为画面左、画面右；每项含 `name`、`box`、`ankle`、可选 `exclude_rects` |
| `arms` | 可省略；每项含 `name`、`box`、`pivot`、逐帧 `angles_degrees`、可选 `exclude_rects` |
| `poses[].stage` / `duration_ms` | 动作阶段标签和当前帧的播放时长，时长为正的 10ms 倍数 |
| `poses[].body_y` | 地面帧的整数身体位移，正值向下；空中填 `null` |
| `poses[].flight_time_ms` | 空中帧距起飞的时间；地面填 `null`。`push_off` 起算为 0，`contact` 对应总腾空时间 |
| `poses[].leg_down_px` / `leg_inset_px` | 空中相对身体的腿下垂与左右各自向内位移；地面为 0 |
| `preview` | GIF 裁框、整数放大倍数和背景色；不改变透明 PNG |

## 这次认可的 12 帧

源图鞋底为 y=154，理论跳高 28px、腾空 400ms。手臂随动作摆动，提包手保持相对衣身稳定。

| 帧 | 阶段 | 身体 y | 腾空时刻 ms | 腿下垂 / 向内 px | 时长 ms |
|---|---|---:|---:|---|---:|
| 1 | rest 站立 | 0 | — | 0 / 0 | 240 |
| 2 | anticipation 蓄力 | 2 | — | 0 / 0 | 80 |
| 3 | compression 压低 | 4 | — | 0 / 0 | 100 |
| 4 | push_off 蹬地 | 0 | 0（地面） | 0 / 0 | 60 |
| 5 | ascending 上升 | −14 | 60 | 0 / 0 | 80 |
| 6 | near_apex 接近顶点 | −25 | 140 | 1 / 1 | 100 |
| 7 | turning_down 转向下降 | −27 | 240 | 1 / 1 | 100 |
| 8 | descent 下降 | −14 | 340 | 0 / 0 | 60 |
| 9 | contact 触地 | 0 | 400（地面） | 0 / 0 | 50 |
| 10 | absorb 缓冲 | 3 | — | 0 / 0 | 80 |
| 11 | recover 回升 | 1 | — | 0 / 0 | 90 |
| 12 | rest 站稳 | 0 | — | 0 / 0 | 300 |

总长 1340ms。12 张 PNG、11 个不同画面、12 个 GIF 实存帧；首末相同是有意的站稳停顿，不为凑独特帧数改动像素。配置中的地面帧 `flight_time_ms` 都是 `null`，表内 0/400 仅说明时间边界。

其他帧数需重新分配阶段与时长，保留蓄力、起飞、顶点附近、下降、触地、缓冲、回稳；重新按时间采样。不要截断、重复这 12 项或用透明叠化凑数。深蹲、明显屈膝、转身或翻转需要新姿态素材，不直接放大本方案的压低幅度。

## 验收与交付

- 检查每条腿的原始 RGBA 经整数平移仍相同，身体局部固定区域保持原像素；再目视检查遮挡后的裤腿和鞋型。
- 地面帧脚底不滑动、不下沉；空中鞋底离地。身体、手臂和腿都不得被画布裁掉。
- 检查蓄力和落地的身体位移、衣身覆盖腿根的量、腰部和袖口连接、手提包与尾巴是否保持。
- 将合成站姿与原图对照：清除矩形可能误删腿间胯部，重叠裁框可能重复叠加半透明边缘。整腿像素保留不等于整张站姿与原图完全相同；新角色需单独检查这些接缝。
- 查看全部联系表及腿根放大图，特别检查蹬地到腾空、下降到触地，以及最后两帧到最初两帧。有播放器时检查播放；没有时如实记录未播放。
- 输出透明 PNG、`preview.gif`、图集、配置、运动记录、`validation.json` 与 `result.zip`。数值验证只报告可测条件，视觉与自然程度留给实际检查和用户反馈；将检查记录写入运行目录的 `visual-review.json`。
