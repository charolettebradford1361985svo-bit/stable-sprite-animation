# 保留原腿型的部件走路

适合朝向不变、双腿可以从原图分离的小步像素走路。仅使用现有素材与本地渲染，不需要生图服务。若两腿严重遮挡、缺少完整鞋子或需要转身/深蹲等新轮廓，先补齐素材或换制作方法。

斜侧人形角色若出现整腿开合跳、近远腿身份互换或手臂只抖动，转读 [斜侧角色走路](three-quarter-walk.md)。下文的整腿刚性运动和“身体最后覆盖”针对本路径，不应阻止另一种结构采用屈膝或近侧手臂覆盖身体。

## 这次成功的关键

整组 AI 图集能保持脸，却会把多帧画成同一脚反复踢出；两节骨骼 IK 虽能保证交替，也可能把短粗腿变成细长的 Z 形。此次被用户认可的是：**每条裤腿和原鞋作为一个完整部件，只作小角度刚性旋转和平移。** 没有换鞋、镜像、分膝、拉长或压细。

动作由连续相位决定：支撑脚向后移动，摆动脚抬起并向前；左右脚错开半周期。每帧以实际可见脚底像素对齐地面或抬脚高度。脚形、衣身、配饰来自同一份原图。

先选部件，再定运动幅度。短腿不要直接套人类长腿的步幅；从短步、小抬脚开始，查看实际尺寸下是否可辨。可允许身体整层轻微整数起伏、空手小幅摆动；身体必须绝对固定时，起伏为零。提包手可保持相对衣身稳定，具体依动作而定。

需要提包手摆动时读取 [提包手臂](carrying-arm.md)。用户要求有腾空的跑步时读取 [短腿跑步](cutout-run.md)，不沿用本脚本“至少一脚支撑”的走路约束。

## 配置与运行

agent 查看输入后创建配置，用户不用手写坐标：

```text
python <skill-dir>/scripts/cutout_walk.py --image <transparent-character.png> --config <walk.json> --out <new-output-dir>
```

配置示例见 [已认可的鳄鱼 12 帧配置](examples/croc-walk-12.json)。它仅适合此次 **200×200** 的源图，是可复现示例，不能按角色名称自动套用到别的尺寸或图。脚本不包含图片、模型、密钥或机器路径。

所有矩形都是输入画布坐标的 `[left, top, right, bottom]`，右下边界不包含；锚点也是输入画布坐标。没有逐部件重新定尺寸这一步。确保输入有足够留白，裁切失败时修画布或配置，不忽略错误。

| 字段 | 含义 |
|---|---|
| `frame_count` / `durations_ms` | 用户指定帧数；每帧时长为正的 10ms 倍数。重复画面和 GIF 合帧如实报告 |
| `ground_y` | 可见鞋底所在的像素行 |
| `gait.stride_px` / `lift_px` | 单侧前后幅度与抬脚高度，根据原腿长度调整 |
| `gait.stance_fraction` | 支撑相位占比，至少半周期以保证总有一脚支撑；示例为 7/12 |
| `gait.leg_swing_degrees` / `direction` | 整腿小幅倾斜；行进方向只影响轨迹，不翻转原鞋 |
| `body.clear_rects` | 从固定底层移除将被动画化的原腿/手臂，避免重影；不要删掉包、尾巴或邻近躯干 |
| `body.offsets_y` | 每帧整层整数位移；省略时为零。批准示例仅 ±1px |
| `body.fixed_boxes` | 检查原像素的区域；逆向补偿身体位移后，RGBA 应与原图一致 |
| `legs` | 两项，按后到前合成；`name`、整腿含鞋的 `box`、脚踝 `ankle`。当前脚本的两个 `phase` 分别为 0 与 0.5，从接触相开始 |
| `exclude_rects` | 某部件裁框误含邻近手、包等内容时剔除，仍使用输入画布坐标 |
| `arms` | 可省略；各项为 `name`、`box`、`pivot`、`swing_degrees`、可选 `phase`，只做小幅刚性摆动 |
| `preview` | GIF 裁框、整数放大倍数和背景色；PNG 保持原画布尺寸与透明通道 |

部件切口要藏在衣身底层之下，保留足够重叠，身体最后覆盖。脚本不会修补原图中根本不存在的轮廓；必须目视检查胯部、袖口和配饰遮挡。

## 已认可样例的节奏

原鳄鱼使用前后幅度 3.2px、抬脚 2.5px、整腿倾斜 ±6°、空手 ±4°，12 帧每帧 90ms。身体起伏为：

```text
1, 0, -1, -1, 0, 1, 1, 0, -1, -1, 0, 1
```

这里直接存整数序列，避免 `round(cos(...))` 在浮点半整数处造成两半周期不一致。对其他帧数重新安排等相位采样，不截断或重复这 12 项来凑帧数。奇数帧数仍用半周期相位差，不能宣称它等于整数张帧的偏移。

该配置让两条腿分别在 3–6、9–12 帧摆动；第 12 帧的抬脚落入第 1 帧支撑，另一只脚继续后移。首末不是同一张图，不插入静止终点。参数是这个角色的经验值，不是所有角色的标准答案。

## 验收

- 检查刚性矩阵没有缩放或镜像；最近邻旋转仍会产生轻微像素台阶，不能称旋转后每个像素位置不变。
- 检查支撑脚实际接地、无穿地、始终至少一脚支撑，并看两条腿是否各自完成一次摆动。只盯头部稳定或固定脚底高度会漏掉乱步。
- 将腿部放大图与原图对照：短粗轮廓、鞋尖方向、腿宽、道具是否保住；没有断肢，也没有把裁框内的邻近手一起带着走。
- 检查 `N-1→N→1→2` 的方向、落脚、遮挡和身体位移；报告的 `body_motion` 包含相邻位移、末→首位移及偶数帧的半周期对称性。这些是诊断，不自动证明自然；身体起伏要受控，不能以“自然”替用户取消绝对固定要求。
- 输出 `frames/`、GIF、图集、配置、`motion.json`、`validation.json`、ZIP。留下实际视觉检查记录。形状保真与循环运动检查不能代替用户对自然程度的评价。
